## 正文成稿（可直接复制发布）

用 Mac 的 AI 重度用户和跨境电商人，大概率都遇到过同一个割裂的日常：

为了稳定使用 Claude Desktop、Claude Code 或各种海外开发者服务，**不得不把 macOS 的地区与时区常年锁在美区（比如美西 PST/PDT）**；但自己平时在国内生活办公、跟国内团队对表，甚至还要盯亚马逊 / TikTok Shop / 独立站的北美节点——系统一锁美区，麻烦就来了：

1. **上午十点看一眼 Mac 日历，还在显示昨天**，开个短会总要先心算「今天到底是几号、差 15 还是 16 小时」；
2. **随手按系统日历新建一条日程**，默认记成了美西时间（等于北京凌晨两三点），经常闹乌龙；
3. **全天事件跨区串天**，原本记在某天的促销节点或生日，在时差换算下被拆成跨两天；
4. **节假日信息割裂**：美区系统看不到国内调休补班和农历节气，国内日历又缺美国联邦假期和黑五/网一/618/双11 节点，夏冬令时切换一周还得手忙脚乱重算会期。

为了彻底解决这个痛点，我在我最喜欢的开源轻量菜单栏日历 [**Itsycal**](https://github.com/sfsam/Itsycal)（MIT 协议）基础上做了深度定制与双时区重构，今天正式打包开源：**Itsycal DualTZ v1.0.0**。

### 核心解决什么问题？

**一句话：系统继续稳稳留在美区，日历体验全面接管回北京时间，美西时间与跨境节点作为精准参考随手可见。**

- **主视觉与菜单栏双时区**：菜单栏自定义模板开箱支持 `{BJ:...}`（北京）、`{NY:...}`（美东）、`{UTC:...}`、`{diff}`（跨天差）和日夜图标；下拉弹窗顶部用超大字号置顶「北京时间 + 星期 + 农历」，右上角保留美西 PST/PDT 实时对照。
- **按北京时间建日程 + 深夜防误伤预警**：点击 `+` 新建日程默认锚定北京时间（无 AM/PM 歧义的 24 小时制）；如果你排的时间折算成美国团队时间落在了 **凌晨 00:00–06:59**，底部会直接亮起 **橙色 `🌙` 深夜预警**。全天日程自动按浮动日期锁定单日，不会跨 16 小时串天。
- **双今日对比 & “回到今天”直指北京今日**：美西昨日、北京次日分界时段，月历上用蓝框高亮「北京今日」、灰框轻量标注「美西今日」，点“今”默认回到北京日期。
- **一套网格看全「中国调休 + 农历节气 + 美国联邦假日 + 跨境大促」**：
  - 内置 2025–2027 国务院放假与周末调休补班（绿 `休` / 橙 `班`，支持设置里一键在线更新或导本地 JSON）；
  - 自带 24 节气与农历；
  - 标注美国 11 个联邦假日（`US` 徽章）与黑五/网一，同时提供独立的 **跨境营销节点开关**（情人节、母亲节、父亲节、618、万圣节、双11、平安夜），不用随时关闭保持极简。
- **跨时区排会 & 会议直达**：
  - 可选展开 **96 槽位北京时间排会时间轴**，绿区直标中美共同黄金时段，夏/冬令时切换前 7 天顶部温和提醒；
  - 新增识别 **飞书（Feishu / Lark）** 与 **腾讯会议（WeMeet）**，会前 **15 分钟菜单栏自动显示轻量倒计时**（如 `· 10m后开会`）；
  - 右键日程一键 **「复制双时区邀约」**，直接贴进飞书或微信群。
- **中英文免重启热切换 & 原版完全共存**：设置页顶部支持一键切换简体中文 / English；应用采用独立 Bundle ID，可以和你原本装的 Itsycal 并排运行互不覆盖，首次启动还会把原版字号和勾选的日历源自动迁过来。
