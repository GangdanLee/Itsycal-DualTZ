# 产品需求规格说明书（PRD）：Itsycal DualTZ

- **文档版本**：v1.0
- **基于上游版本**：`sfsam/Itsycal` v0.29.0（MIT License，Commit `287576c`）
- **开发分支**：`feat/dual-timezone`
- **适用系统**：macOS（本机环境：macOS 27.0 / Xcode 27.2，主系统时区 `America/Los_Angeles`）

---

## 1. 产品背景与核心场景

### 1.1 背景痛点
用户日常将本地 Mac 系统时区固定设为美国洛杉矶时间（`America/Los_Angeles`，冬令时 PST `UTC-8` / 夏令时 PDT `UTC-7`），但同时重度需要对齐**北京时间**（`Asia/Shanghai`，恒定 `UTC+8`，无夏令时）。原版 `Itsycal` 仅绑定单个系统当前时区，跨时区使用时存在以下刚性痛点：

1. **跨天日期混淆比小时差更致命**：美西比北京慢 16 小时（冬令时）或 15 小时（夏令时）。每天美西 08:00（冬令时）或 09:00（夏令时）之后，北京即进入下一个自然日（且周几同步后移一天）。仅看时间不看日期极易约错日子。
2. **夏令时（DST）动态切换陷阱**：美国每年 3 月第二个周日切换夏令时、11 月第一个周日恢复冬令时；中国全年不实行夏令时。心算加减时差或设定固定北京周期例会时，每年切换周极易偏移 1 小时。
3. **日历查看与新建日程割裂**：点开弹窗只能看到 LA 的“今天”，日程行只显示 LA 时间，按北京时间沟通的会议无法直接以 `Asia/Shanghai` 写入 `EventKit`。

### 1.2 三大核心使用场景
- **场景 A：中美跨时区排会与团队协作**：快速判断双方黄金重叠工作窗、查看双时区日程安排、以北京时间录入周期例会、直接复制双时区排会文案发到沟通群。
- **场景 B：跨境电商业务运营节点**：把控黑五（Black Friday）、网一（Cyber Monday）、感恩节、春节工厂物流窗口、美国银行/USPS 休假日、国内法定休假调休与周报复盘周数对齐，同时在美西 DST 切换前获得提前预警。
- **场景 C：国内亲友日常联系**：扫一眼菜单栏或时间轴即可感知北京此刻是白天还是深夜，避免在深夜时段打扰国内家人或同事。

## 2. 核心设计原则

1. **100% 继承原版手感与现有自定义偏好**：
   - 完整保留原版**自由选择一周起始日**（`WeekStartDOW`：0=周日 ～ 6=周六，默认保留用户当前周一 `1` 设置）、指定列高亮（`HighlightedDOWs`）、周数显示（`ShowWeeks`）、三档字号（`SizePreference`：小/中/大）、深浅主题（`ThemePreference`）及日历源过滤能力。
   - 首次启动可安全平滑导入原版 `Itsycal`（`com.mowglii.ItsycalApp`）已配置的用户偏好，同时通过独立 Bundle ID 实现与 `/Applications/Itsycal.app` 共存，互不覆盖。
2. **全功能模块化可插拔（Feature Flags）**：
   - 所有新增增强能力均设计为独立开关与模块，全部提供偏好设置一键开启/关闭。用户可“先全量体验，不需要的随时一键隐藏”，工程侧亦支持独立裁剪。
3. **隐私与离线优先**：
   - 所有日历读取与写入继续完全本地通过 macOS `EventKit` 完成，无埋点、无遥测；农历、节气、美国联邦假日及跨境固定节点全离线计算，仅用户手动点击同步最新国务院调休数据时才发起一次受控 HTTPS 请求。

## 3. 功能需求详述（F1–F7）

### F1. 自定义多时区菜单栏格式引擎（Menu Bar Custom Formatter）

- **设计动机**：macOS 顶部菜单栏最右侧已有系统原生 LA 时钟，菜单栏右侧空间受刘海屏限制寸土寸金，固定写死双时区文案既占空间又不符合所有用户习惯，因此必须做成**完全自定义模板引擎**。
- **格式语法规范**：
  1. **100% 向后兼容原版 ICU 日期格式**：块外字母（如 `EEE HH:mm`、`M/d h:mm a`）默认按系统本地时区（`America/Los_Angeles`）渲染。
  2. **多时区块语法 `{TZ:<ICU格式>}`**：
     - 内置别名：`{BJ:...}`（`Asia/Shanghai` 北京时间）、`{LA:...}`（`America/Los_Angeles` 美西时间）、`{NY:...}`（`America/New_York` 美东时间）、`{UTC:...}`（协调世界时）。
     - 通用扩展：支持任意标准 IANA 时区标识符，例如 `{Asia/Tokyo:HH:mm}`。
  3. **智能动态占位符（Smart Tokens）**：
     - `{diff}`：仅当北京与 LA **不在同一自然日**时输出 `+1d`，同日时输出空字符串（零冗余）。
     - `{diff_cn}`：跨天时输出 `次日`，同日时输出空字符串。
     - `{bj_dn}`：按北京当前小时自动输出日夜微图标：`☀️`（07:00–19:59）或 `🌙`（20:00–06:59）。
     - `{dst_gap}`：动态输出当前中美时差小时数（`16h` 或 `15h`）。
- **设置页交互设计**：
  - 提供自由文本格式输入框 + 语法速查提示条。
  - **双态实时预览条**：输入框下方实时渲染同一模板在“今日同日时段（如 LA 06:30 / 京 22:30）”与“今日跨天时段（如 LA 16:30 / 京 次日 08:30）”的最终显示效果。
  - **一键预设胶囊（Presets）**（点击即填入，可继续二次编辑）：
    - 预设 1（极简北京 · 默认）：`{BJ:EEE HH:mm}`（搭配日历图标默认显示北京日期，呈 `[18] 周三 10:06`）
    - 预设 2（日夜图标 · 搭配系统时钟）：`{bj_dn} {BJ:HH:mm}`
    - 预设 3（带月日 · 搭配系统时钟）：`{BJ:M/d HH:mm}`
    - 预设 4（双时区 · 前美西后北京）：`HH:mm · {BJ:EEE HH:mm}`
    - 预设 5（跨境三区全览）：`HH:mm · {BJ:HH:mm}{diff} · NY{NY:HH:mm}`
  - **菜单栏日历框图标控制**：保留原版“显示月份/星期/隐藏图标”设置，新增“日历框数字跟随：**`北京日期（默认）` / `美西日期`**”选项，默认让菜单栏左侧图标与文字统一表示北京时间，与右侧系统原生 LA 时钟形成零歧义左右对照。
- **开关控制**：`kDualTZMenuBarEnabled`（默认开启）。

### F2. 弹窗“北京时间主视觉区”与月历“双今标”

- **交互规格**：
  - **顶部北京时间主视觉区（Hero Header）**：点开弹窗第一眼即看到大字号（`26pt`）等宽北京时间、北京日期与星期、北京日夜状态（`☀️`/`🌙`）及农历/节气/调休摘要；右侧并列呈现美西时间（`美西 PST/PDT` + 时分 + 日期星期），不再额外堆砌易引发误解的“次日 +16h”胶囊。`NY`/`UTC` 辅助参考默认关闭，可在设置中按需开启。
  - **月历双今标（三态纯视觉区隔，去掉格内“京/LA”冗余文字）**：
    - **北京今日（主高亮）**：在对应北京当日格子绘制**主题蓝色实线圆角框 + 柔和淡蓝底色**（与顶部蓝色“北京时间”天然呼应，悬浮提示 `北京今日`）。
    - **美西今日**：绘制**前景细实线圆角空心框**（无底色填充，悬浮提示 `美西今日`）；当两地处于同一公历日时自动合并为单格。
    - **用户点选日期**：采用**无边框纯柔和次级底色填充**，彻底与美西今日空心框区分开。
  - **快捷回今**：点击月历栏“今”按钮或按快捷键定位到今天，跨月时一键切换。
- **开关控制**：`kShowBeijingHeroHeader`（默认开启）、`kShowDualTodayIndicator`（默认开启）。

### F3. 农历、二十四节气、中美法定节假日与国务院调休（`休`/`班`）+ 跨境节点

- **单格副标题与 Apple 原生风微字排版规则**：
  - 采用无粗糙色块的极简微字排版（弹窗默认宽度约 `320pt`），每个公历日格下方最多显示 **1 行副标题**，按以下优先级严格互斥取最高项：
    1. 中国法定节日 / 传统大节（春节、清明、端午、中秋、国庆、元旦、劳动节）
    2. 跨境运营核心节点 / 美国联邦假日（感恩节、黑五、网一、圣诞节、独立日等）
    3. 二十四节气（立春、清明、夏至、冬至等）
    4. 农历日（初一显示农历月份如 `十月`，其余显示 `初二`、`十五`、`廿八`）
  - **右上角无底色微字角标**：
    - 中国国务院公布法定放假日：细体绿字 `休`
    - 中国国务院公布周末调休补班日：细体红字 `班`
    - 美国联邦假日（银行/ACH结算/USPS停运日）：细体 `US`
    - 同一天若同时命中中国调休状态与美国假日，以中国 `休/班` 角标优先于角标位，美国假日名称保留在副标题或悬停 Tooltip 完整展示。
  - **悬停详情增强**：鼠标悬停在某日期格子上时，除显示当天日程外，Tooltip 顶部追加一行紧凑摘要：`农历 · 节气 · 中美节假日/调休说明 · 跨境节点说明`。
- **数据来源与免重编更新机制**：
  - **离线确定性计算**：农历与二十四节气基于 Foundation `Calendar(identifier: .chinese)` + 天文节气算法；美国联邦假日（含周末顺延观察日规则）及感恩节/黑五/网一（11月第4个周四及次日、下周一）采用规则引擎离线永久精准计算。
  - **国务院调休 JSON**：工程内置 `2025–2027` 年中国国务院放假调休 JSON；每年年底国务院公布下一年放假安排后，用户可在设置页点击 **“在线同步最新节假日 JSON”** 或 **“导入本地 JSON 文件”** 即时生效，无需重编应用。
  - **非固定日期大促说明**：Amazon Prime Day 等每年日期临时公布的活动，不写死在代码中，推荐通过独立日历订阅或用户自定义节假日 JSON 节点条目录入。
- **独立开关控制**：
  - `kShowLunarAndSolarTerms`（农历与二十四节气，默认开启）
  - `kShowChinaHolidaysAndWorkdays`（中国法定假日与 `休`/`班` 调休，默认开启）
  - `kShowUSHolidaysAndCrossBorder`（美国联邦假日与黑五/网一跨境节点，默认开启）

### F4. 日程列表（Agenda）与悬停提示（Tooltip）双时区同显

- **展示规则**：
  - **非全天日程（Timed Events）**：
    - 保持原版“第一行完整标题、第二行时间”结构，避免标题被时间挤占。
    - 第二行采用**“前灰（美西本地）· 后蓝（北京对照）”**富文本排版，去掉多余的 `LA` / `京` 前缀：
      - 同日时段：`07:00–07:20 · 23:00–23:20`
      - 跨天时段：`18:00–19:00 · 周五(11/27) 10:00–11:00`（起点跨天时自动带出北京星期与月日，以主题蓝色高亮显示，零冗余汉字）。
  - **全天事件（All-day Events）与生日/纪念日**：
    - 严格保持 `全天`，**禁止套用 `+15h/+16h` 时区换算**，防止原本单日全天事件被错误拆成跨两天显示。
  - **Tooltip 同步**：悬停日期弹出的事件气泡同样遵循上述规则，并标明全天事件不受时差影响。
- **开关控制**：`kShowDualTZInAgenda`（默认开启）。

---

### F5. 新建日程时区切换（`[北京时间 | 美西时间]`）

- **交互规格**：
  - 在 `+` 新建日程弹出框中，当取消勾选“全天”时，提供分段选择器：**`[北京时间 | 美西时间]`**。
  - 用户选择 **`北京时间`** 时，开始/结束时间直接按 `Asia/Shanghai` 录入；下方以自然语言轻提示对端时间（`对应美西：11月17日(周二) 18:00–19:00 PST（自动适应夏令时）`），避免展示底层开发术语。
  - 点击保存时，底层将 `EKEvent.timeZone` 显式写入 `[NSTimeZone timeZoneWithName:@"Asia/Shanghai"]`（全天事件遵循 `EventKit` 规范设 `timeZone = nil`）。
  - **长期收益**：固定“北京时间每周四 10:00”的周期例会在每年 3 月、11 月美西切换夏令时后，macOS 日历会自动保持北京时间不变，永不偏移 1 小时。
- **开关控制**：`kAllowBeijingEventCreation`（默认开启）。

---

### F6. 滑动时间轴换算器（Time Scrubber · 默认关闭按需启用）

- **交互规格**：
  - **默认关闭以保持主界面极简**：仅当用户在设置页勾选 `kEnableTimeScrubber` 时，主弹窗工具栏才渲染 `⏱ 排会换算` 按钮及折叠面板；未勾选时不在主页面占据任何视觉元素。
  - **联动日期与动态夏令时**：时间轴默认以月历当前选中的日期（`selectedDate`）作为基准日。用户在 11 月点击明年 3 月 25 日排期时，系统自动按 3 月 25 日所处夏令时计算 `15h` 时差，而非错误套用当前的 `16h`。
  - **24 小时滑块与作息色带**：支持 `00:00` – `23:45` 连续拖动（15 分钟步进），滑轨直接呈现作息分布三色带（睡眠暗区 / 早晚琥珀区 / **🟢 黄金沟通绿区**），左右双栏直观对照 `北京时间` 与 `美西 PST/PDT`，并提供 `此刻`、`北京 09:30`、`北京 14:00`、`美西 09:00`、`美西 17:00` 快捷跳转。
  - **可选第三参考行**：`kShowThirdRefTimezones`（默认关闭，开启后附带 `NY` 与 `UTC`）。
  - **一键复制**：点击“复制”将双时区文本复制到系统剪贴板，例如：`北京时间 2026-11-18(周三) 09:30 | 美西 2026-11-17(周二) 17:30 PST`，按钮短时变为“已复制 ✓”。
- **开关控制**：`kEnableTimeScrubber`（**默认关闭**）、`kShowThirdRefTimezones`（**默认关闭**）。

---

### F7. 美西夏/冬令时（DST）切换提前 7 天预警条

- **交互规格**：
  - 每次打开主弹窗时，计算从今天到下一个 `America/Los_Angeles` 夏令时/冬令时跳变点（`nextDaylightSavingTimeTransition`）的剩余天数。
  - 当剩余天数 `0 <= days <= 7` 时，在月历顶部显示一条紧凑柔和的提醒条：
    - 示例（3月切换前）：`⚠️ 5天后 (3月14日) 美西切换夏令时，中美时差将变为 15h`
    - 示例（11月切换前）：`⚠️ 4天后 (11月1日) 美西恢复冬令时，中美时差将变为 16h`
  - 平时距离切换 > 7 天时，预警条完全隐藏，零空间占用；允许用户点击右侧 `×` 本周期忽略提示。
- **开关控制**：`kShowDSTTransitionWarning`（默认开启）。

## 4. 验收标准（AC）与边界矩阵

| 编号 | 验收场景 | 预期结果 |
| :--- | :--- | :--- |
| AC-1 | 菜单栏自定义引擎 | 输入 `{bj_dn} 京{BJ:HH:mm}{diff}`，在 LA `07:59 PST` 输出 `🌙 京23:59`；到达 `08:00 PST` 时自动切换为 `☀️ 京00:00+1d` 或 `🌙 京00:00+1d`（按日夜规则 `🌙` 且 `+1d` 准确出现）。 |
| AC-2 | 保留原版习惯配置 | 一周起始日从 `周一` 改为 `周日` 时，月历表头、单元格排列、周数计算与高亮列同步切换，且农历、双今标、假日角标对应日期完全正确。 |
| AC-3 | 全天事件时区隔离 | 创建一个 2026-11-26 感恩节全天事件，Agenda 与 Tooltip 均显示在 11/26 当天并标记为“全天”，不出现跨天北京时刻后缀。 |
| AC-4 | 跨夏令时日期换算 | 在冬令时期间（2026-11-18）选中 2027-03-15（美西夏令时生效后），在时间轴选择 LA 17:00，对应北京必须显示 2027-03-16 08:00（15h 差），而非 09:00（16h 差）。 |
| AC-5 | 按北京时间新建日程 | 新建弹窗切至 `北京时间` 录入 `2026-11-19 10:00` 保存，在原生 Calendar.app 中查看该事件属性，时区必须为 `Asia/Shanghai` 且在 LA 视图下显示为 `11/18 18:00 PST`。 |
| AC-6 | 离线与网络故障兜底 | 断网状态下启动应用，农历、节气、美国假日、黑五网一及内置 2025–2027 国务院调休全部正常显示；在线同步失败时保留旧数据并提示错误，不崩溃。 |
| AC-7 | 原版共存与无覆盖 | 安装 `Itsycal DualTZ.app` 后，原 `/Applications/Itsycal.app` 可保留；不会弹出官方 Sparkle 更新提示将定制版替换回原版。 |
